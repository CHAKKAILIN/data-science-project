# Flight Details Exploratory Data Analysis
## The problem or research question
What are the distribution characteristics of flight data, and what relationships exist between flight attributes?

## Dataset source and usage permissions
Dataset: flight_details.csv. This dataset is provided for CISC7204 course practice. It can be used for academic learning and non-commercial analysis. No private or restricted data included.

## Methods and tools used
Python 3.9
pandas: data loading, cleaning and preprocessing
matplotlib & seaborn: data visualisation (boxplot, correlation heatmap)
Jupyter Notebook: run and document analysis workflow

## Key findings and one limitation
Key findings: There are obvious differences in value distribution across different flight categories. Some flight variables show moderate correlation. Visualizations help identify outliers in flight data.
Limitation: This is only descriptive exploratory analysis. No machine learning prediction model is built. We cannot infer causal relationships, only correlation.

## Instructions for running the analysis
1. Clone this repository to local machine.
2. Install required packages: `pip install -r requirements.txt`
3. Open `flight_analysis.ipynb` with Jupyter Notebook.
4. Run all cells sequentially to reproduce the analysis and charts.
